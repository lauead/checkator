# Zadání pro vývojové chaty

Každý samostatný úkol ulož jako soubor Markdown v tomto adresáři. V zadání odkazuj na schválené části rozsahu a architektury, které vývojový chat potřebuje.

## Šablona

```markdown
# Název úkolu

## Cíl

Co má po dokončení fungovat?

## Podklady a návaznosti

Která rozhodnutí a další úkoly jsou pro práci potřeba?

## Výstup

Jaké části projektu má změna dodat?

## Kritéria přijetí

Podle čeho poznáme, že výstup splňuje zadání?

## Ověření

Jak ověřit jednotlivá kritéria a v jakém prostředí?
```
